## hyper3d-gen2-260112

### 基本信息

| 字段 | 内容 |
|---|---|
| 模型名称 | `hyper3d-gen2-260112` |
| 任务场景 | 文生 3D、图生 3D |
| 计量单位 |  |
| 模型功能说明 | 根据英文提示词或 1-5 张图片生成 3D 模型 |

### 核心参数

| 参数 | 必填 | 类型/取值 | 说明 |
|---|:---:|---|---|
| `model` | 是 | string | `hyper3d-gen2-260112` |
| `metadata.prompt` | 条件必填 | string，最长 400 字符 | 仅英文；文生 3D 必填，图生 3D 可选 |
| `metadata.images` | 条件必填 | array，1-5 张 | 图生 3D 必填；支持 HTTP URL 或 data URI Base64；格式 jpg/jpeg/png；像素小于 4096×4096；单图不超过 30 MB |
| `metadata.file_format` | 否 | `glb` / `obj` / `usdz` / `fbx` / `stl` | 输出格式，默认 `glb` |
| `metadata.material` | 否 | `pbr` / `shaded` / `all` / `none` | 材质类型，默认 `pbr` |
| `metadata.mesh_mode` | 否 | `raw` / `quad` | 网格类型，默认 `quad`；`raw` 为三角面，`quad` 为四边面 |
| `metadata.face_count` | 否 | integer | 精确面数；`raw` 范围 `[500,1000000]`，默认 500000；`quad` 范围 `[1000,200000]`，默认 18000；与 `quality_level` 同传时优先 |
| `metadata.quality_level` | 否 | `high` / `medium` / `low` | Raw：high=500k（默认）、medium=150k、low=20k；Quad：high=50k、medium=18k（默认）、low=8k |
| `metadata.seed` | 否 | integer，`[0,65535]` | 随机种子 |
| `metadata.use_original_alpha` | 否 | boolean | 是否保留图片透明轮廓，默认 `false` |
| `metadata.hd_texture` | 否 | boolean | 是否启用 HD 纹理，默认 `false` |
| `metadata.addons` | 否 | `high_pack` | `high_pack` 表示 4K 纹理；不传为 2K 纹理 |
| `metadata.ta_pose` | 否 | boolean | 类人模型是否强制 T/A Pose，默认 `false` |
| `metadata.bbox_condition` | 否 | array | 模型边界框尺寸 `[宽,高,长]` |

## hunyuan-3d-pro-3.0

### 基本信息

| 字段 | 内容 |
|---|---|
| 模型名称 | `hunyuan-3d-pro-3.0` |

| 计量单位 |  |
| 模型功能说明 | 支持提示词、主图及多视角图片生成 3D 模型，并支持 LowPoly、Sketch 和纯几何模式 |

| 参数 | 必填 | 类型/取值 | 说明 |
|---|:---:|---|---|

| `metadata.generate_mode` | 否 | `normal` / `low_poly` / `sketch` | 生成模式，默认 `normal` |
