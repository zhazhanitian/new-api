| 字段 | 内容 |
|---|---|
| 模型名称 | `doubao-seedream-5-0-260128` |
| 文档名称 | Seedream 5.0 Lite |
| 任务场景 | 文生图、图生图、多图融合 |
| 计量单位 |  |
| 模型功能说明 | 根据提示词或最多 14 张参考图生成图片，支持多张组图生成 |

### 核心参数

| 参数 | 必填 | 类型/取值 | 说明 |
|---|:---:|---|---|
| `model` | 是 | string | `doubao-seedream-5-0-260128` |
| `prompt` | 是 | string | 图像描述提示词，建议不超过 300 个汉字或 600 个英文单词 |

| `size` | 否 | `2K` / `3K` / `4K` / `宽x高` | 分辨率档位与像素值不可混用；默认 `2048x2048`；总像素范围 `[3,686,400, 16,777,216]`，宽高比 `[1/16, 16]` |
| `response_format` | 否 | `url` / `b64_json` | 默认 `url`，图片链接有效期 24 小时 |
| `output_format` | 否 | `jpeg` / `png` / `webp` | 输出图片文件格式；不传时使用模型默认格式 |
| `watermark` | 否 | boolean | 是否添加水印，默认 `false` |
