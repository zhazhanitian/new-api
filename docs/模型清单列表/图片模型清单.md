# 图片模型

`size` 只写宽x高。`resolution` 是分辨率档位。`ratio` 是宽高比。`quality` 只表示 `low` / `medium` / `high` / `xhigh` / `max`。旧写法 `size=16:9`、`quality=2K`、`quality=hd`、`quality=standard` 会返回 400。对照见 [图片四字段迁移对照](图片四字段迁移对照.md)。

## doubao-seedream-5-0-260128

### 基本信息

| 字段 | 内容 |
|---|---|
| 模型名称 | `doubao-seedream-5-0-260128` |
| 文档名称 | Seedream 5.0 Lite |
| 任务场景 | 文生图、图生图、多图融合 |
| 计量单位 |  |
| 模型功能说明 | 根据提示词或最多 14 张参考图生成图片，支持多张组图生成 |

### 核心参数

| 参数 | 必填 | 类型/取值 | 说明 |
|---|:---:|---|---|
| `model` | 是 | string | `doubao-seedream-5-0-260128` |
| `prompt` | 是 | string | 图像描述提示词，建议不超过 300 个汉字或 600 个英文单词 |
| `image` | 否 | string / string[]，最多 14 张 | 参考图 URL 或 Base64；支持 jpeg、png、webp、bmp、tiff、gif、heic、heif；单图不超过 30 MB；宽高均大于 14 px；宽高比 `[1/16, 16]`；总像素不超过 36,000,000 px |
| `n` | 否 | integer，`1-15` | 默认 1，表示最多生成张数；实际生成张数不超过 `n` |
| `resolution` | 否 | `2K` / `3K` / `4K` | 默认 `2K`。与 `size` 互斥 |
| `ratio` | 否 | `宽:高` | 可单独出现，也可和 `resolution` 一起。网关追加到 prompt。不能和 `size` 一起 |
| `size` | 否 | `宽x高` | 与 `resolution`、`ratio` 互斥。不传时上游默认 `2048x2048`。总像素 `[3,686,400, 16,777,216]`，宽高比 `[1/16, 16]`。网关只检查宽x高格式 |
| `response_format` | 否 | `url` / `b64_json` | 默认 `url`，图片链接有效期 24 小时 |
| `output_format` | 否 | `jpeg` / `png` / `webp` | 输出图片文件格式；不传时使用模型默认格式 |
| `watermark` | 否 | boolean | 是否添加水印，默认 `true` |
| `extra_fields.guidance_scale` | 否 | number，推荐 `1-5` | 提示词引导强度 |
