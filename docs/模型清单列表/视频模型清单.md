# 视频模型

火山 Seedance、腾讯 VOD 与京东 HappyHorse 的素材以 `metadata.content` 为主。元素 `type` 为 `image_url`、`video_url`、`audio_url`，`role` 为 `first_frame`、`last_frame`、`reference_image`、`reference_video`、`reference_audio`。未写 `role` 时按参考素材提交。`reference_type` 和 `name` 写在对应的那一项上。待编辑视频用 `video_url`。

## doubao-seedance-1-0-pro-250528

### 基本信息

| 字段 | 内容 |
|---|---|
| 模型名称 | `doubao-seedance-1-0-pro-250528` |
| 文档名称 | Seedance 1.0 Pro |
| 任务场景 | 文生视频、首帧图生视频、首尾帧图生视频 |
| 计量单位 |  |
| 模型功能说明 | 根据文本提示词或首帧、首尾帧图片生成视频 |

### 核心参数

| 参数 | 必填 | 类型/取值 | 说明 |
|---|:---:|---|---|
| `model` | 是 | string | `doubao-seedance-1-0-pro-250528` |
| `prompt` | 文生视频时是 | string | 文本描述提示词；图生视频时建议填写以精确描述运动效果 |
| `duration` | 否 | integer，`2-12` | 视频时长，默认 5 秒；超出范围将报错 |
| `resolution` | 否 | `480p` / `720p` / `1080p` | 默认 `1080p` |
| `seed` | 否 | integer | 随机种子，用于控制生成结果的可复现性 |
| `ratio` | 否 | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` | 文生视频默认 `16:9`，图生视频默认 `adaptive` |
| `metadata.return_last_frame` | 否 | boolean | 是否返回视频最后一帧，默认 `false` |
| `metadata.camera_fixed` | 否 | boolean | 是否固定摄像头，默认 `false` |
| `metadata.watermark` | 否 | boolean | 是否添加 `AI 生成` 水印，默认 `false` |
| `metadata.service_tier` | 否 | `default` / `flex` | 服务等级，默认 `default` |
| `metadata.content` | 否 | array | 素材列表。`type` 为 `image_url` / `video_url` / `audio_url`，`role` 为 `first_frame`、`last_frame`、`reference_image`、`reference_video`、`reference_audio`。`reference_type` 与 `name` 写在对应项上 |
