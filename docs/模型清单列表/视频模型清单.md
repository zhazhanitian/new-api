## doubao-seedance-1-0-pro-250528

### 基本信息

| 字段 | 内容 |
|---|---|
| 模型名称 | `doubao-seedance-1-0-pro-250528` |
| 文档名称 | Seedance 1.0 Pro |
| 任务场景 | 文生视频、首帧图生视频、首尾帧图生视频 |
| 计量单位 |  |
| 模型功能说明 | 根据文本提示词或首帧、首尾帧图片生成视频 |

### 核心参数

| 参数 | 必填 | 类型/取值 | 说明 |
|---|:---:|---|---|
| `model` | 是 | string | `doubao-seedance-1-0-pro-250528` |
| `prompt` | 文生视频时是 | string | 文本描述提示词；图生视频时建议填写以精确描述运动效果 |
| `duration` | 否 | integer，`2-12` | 视频时长，默认 5 秒；超出范围将报错 |
| `size` | 否 | `480p` / `720p` / `1080p` / `宽x高` | 默认 `1080p`；传宽高时自动推导分辨率和宽高比 |
| `seed` | 否 | integer | 随机种子，用于控制生成结果的可复现性 |
| `metadata.ratio` | 否 | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` | 文生视频默认 `16:9`，图生视频默认 `adaptive`；外层 `size` 为宽高格式时覆盖此参数 |
| `metadata.return_last_frame` | 否 | boolean | 是否返回视频最后一帧，默认 `false` |
| `metadata.camera_fixed` | 否 | boolean | 是否固定摄像头，默认 `false` |
| `metadata.watermark` | 否 | boolean | 是否添加 `AI 生成` 水印，默认 `false` |
| `metadata.service_tier` | 否 | `default` / `flex` | 服务等级，默认 `default` |
| `metadata.content` | 否 | array | 首帧或首尾帧图片素材；元素使用 `image_url` 类型及 `first_frame` / `last_frame` 角色，尾帧须与首帧同时传入 |
