# 图片四字段迁移对照

`POST /v1/images/generations` 和 `POST /v2/image-tasks` 同时切换。旧字段组合返回 400。

| 模型 | 旧写法 | 新写法 |
|---|---|---|
| Gemini 2.5 / 3 Pro | `size=16:9`，`quality=2K` | `ratio=16:9`，`resolution=2K` |
| Gemini 3.1 | `size=1:8`，`quality=720P` | `ratio=1:8`，`resolution=720P` |
| Kling 2.1 / 3.0 | `size=16:9`，`quality=hd` | `ratio=16:9`，`resolution=2k` |
| Kling 3.0 Omni / O1 | `size=auto`，`quality=4k` | `ratio=auto`，`resolution=4k` |
| Kling Scene | 不传尺寸 | 仍然不传。`size`、`resolution`、`ratio`、`quality` 都会 400 |
| Vidu Q2 | `size=16:9`，`quality=4K` | `ratio=16:9`，`resolution=4K` |
| gpt-image-2 / OG-image-2 | `quality=hd` 或 `standard` | `quality=high` 或 `quality=low`。`xhigh`、`max` 会按 `image2_low` 发给腾讯 |
| gpt-image-2 / OG-image-2 | `size=1024x1024` | 仍然是 `size=1024x1024`。不要和 `resolution`、`ratio` 一起传 |
| Qwen / Hunyuan | `size=1024x1024` | 不变。不要传 `resolution`、`ratio`、`quality` |
| Seedream | `size=2K` | `resolution=2K`。宽高比写 `ratio`，不要写进 `size` |
| Seedream | `size=2048x2048` | 仍然是 `size=2048x2048`。不要和 `resolution`、`ratio` 一起传 |
| APIMart 2.5 / 2.6 | 新模型 | `size` 与 `resolution`/`ratio` 二选一。`quality` 五档原样透传，不传按 `low` |

已提交、还在轮询的任务不受影响。轮询读的是当时存下来的任务数据。
