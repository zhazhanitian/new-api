# 3D 模型测试参数文档

> 本文档用于手动验证 3D 模型提交、查询、字段映射和计费结果。
>
> 参数依据：`docs/3D文档/3D模型渠道接入规范.md`。

## 使用说明

- `BASE_URL` 替换为实际服务地址，`YOUR_API_KEY` 替换为实际 key。
- 提交接口：`POST /v1/3d/generations`。
- 查询接口：`GET /v1/3d/generations/{task_id}`。
- 3D 请求参数统一放在 `metadata` 对象内。
- 图片 URL 可以替换为你自己的测试素材；后处理能力里的 3D 文件 URL 必须替换为真实可下载的 OBJ / GLB / FBX 文件。
- 火山 3D 按查询返回的 `usage.total_tokens` 结算，提交前无法固定预估最终 token。
- 腾讯 3D 按积分结算；下文预期人民币按 `0.12 元/积分`、分组倍率 `1` 估算。

### 1. `doubao-seed3d-2-0-260328` — 图生 3D 最简请求

- **测试目的**：验证 seed3d 图生 3D、`images[].url`、`file_format`、`quality_level` 映射。

  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seed3d-2-0-260328",
    "metadata": {
      "images": [
        { "url": "https://seekingliren.oss-cn-hangzhou.aliyuncs.com/admin/uploads/1785809772583-jq2pzivz.jpeg" }
      ],

## 附：任务结果查询

提交成功后会返回：

```json
{
  "task_id": "task_xxxxxxxx",
  "status": "QUEUED"
}
```

使用返回的 `task_id` 查询：

```bash
curl -X GET "$BASE_URL/v1/3d/generations/{task_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

统一状态：

- `QUEUED`：排队中 / 已提交
- `IN_PROGRESS`：运行中
- `SUCCESS`：成功，结果文件在 `files`
- `FAILURE`：失败，查看 `fail_reason`
- `UNKNOWN`：未知 / 取消

成功响应重点检查字段：

```json
{
  "task_id": "task_xxxxxxxx",
  "model": "hunyuan-3d-pro-3.1",
  "status": "SUCCESS",
  "files": [
    {
      "url": "https://...",
      "format": "glb",
      "preview_url": "https://..."
    }
  ],
  "usage": {
    "input_tokens": 0,
    "output_tokens": 0,
    "total_tokens": 0,
    "credits": 55
  },
  "amount": "6.600000"
}
```
