# 新接入模型测试参数文档

> **说明**
> - `BASE_URL` 替换为实际服务地址，`YOUR_API_KEY` 替换为实际 key
> - 参考图 URL（`image` 字段）需替换为真实可访问图片链接
> - 同步接口：`POST /v1/images/generations`；异步接口：`POST /v2/image-tasks`（推荐）
> - 异步接口提交后用 `GET /v2/image-tasks/{task_id}` 轮询结果

### 12. kling-image-scene — 扩图模式（需提供参考图）

> **注意**：必须传入 `image`（原图），并在 `extra_fields` 中指定 `scene_type="image_expand"` 和 `expansion` 扩图比例。

```bash
curl -X POST "$BASE_URL/v2/image-tasks" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-image-scene",
    "prompt": "以原图风格自然延展画面内容",
    "n": 1,
    "image": ["https://example.com/ref-image.jpg"],
    "extra_fields": {
      "scene_type": "image_expand",
      "expansion": {
        "up": 0.2,
        "down": 0.2,
        "left": 0.4,
        "right": 0.4
      }
    }
  }'
```

> **扩图约束提醒**：各方向取值范围 `[0, 2]`，上下扩充基于原图高度、左右扩充基于原图宽度；新图整体面积不超过原图 3 倍。

## 附：异步任务结果查询

```bash
curl -X GET "$BASE_URL/v2/image-tasks/{task_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

返回 `status` 字段：
- `NOT_START` — 排队中
- `PROCESSING` — 生成中
- `SUCCESS` — 完成，结果在 `output.image_urls` 或 `output.images`
- `FAIL` — 失败，查看 `fail_reason`
