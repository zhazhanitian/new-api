# 图像生成模型价格配置

> 平台对外报价以**人民币**显示，内部计费仍以**美元**结算，**固定汇率 7.3 CNY/USD**（不随市场波动调整）。  
> 表达式值计算公式：`表达式值 = 人民币单价 ÷ 7.3 × 1,000,000`  
> `param("quality")` 读取请求 body 中的原始 `quality` 字段（不做归一化），需兼容用户传入的别名（low/medium/high 等）。

### 8.0 gpt-image-2

#### 价格说明（新价格，2026.5.12 起生效）

**输入图片（参考图）：固定 0.100 元/张，与 quality 和 size 无关，按实际传入张数计费，不随 `n` 翻倍。**

| quality | 1K（元/张） | 2K（元/张） | 4K（元/张） |
|---------|-----------|-----------|-----------|
| low | 0.045 | 0.090 | 0.150 |
| medium | 0.398 | 0.803 | 1.335 |
| high | 1.583 | 3.210 | 5.340 |

> **计费结构**：总费用 = 生成成本（quality × size × n） + 输入图片成本（0.100 元 × 张数）  
> 输入图片成本**不受 quality、size、n 影响**，只看传了几张参考图。

#### 计费表达式

`size` 按**总像素**分档（`pixels()` 解析 `宽x高`，兼容 `x` / `*` / `×` 以及 `1K`/`2K`/`4K`），不要精确匹配字符串。`quality` 需兼容别名：`hd` 与 `high` 同档，`standard`/`low`/未传走 low。

| 档位 | 判定 | 典型 size |
|------|------|-----------|
| 1K | 总像素 ≤ 1024×1024（含未传 size） | `1024x1024`、`1K` |
| 2K | 1024×1024 < 总像素 ≤ 2048×2048 | `1024x1536`、`1024x1792`、`2048x2048`、`2K` |
| 4K | 总像素 > 2048×2048 | `2560x1440`、`2880x2880`、`3840x2160`、`4K` |

```
let q = param("quality");
let px = pixels(param("size"));
let n = param("n") != nil ? param("n") : 1;
let imgCount = param("image") == nil ? 0 : (param("image.#") != nil && param("image.#") > 0 ? param("image.#") : 1);
(
  (q == "high" || q == "hd") ? (
    px > 2048 * 2048 ? tier("high-4K", 731507) :
    px > 1024 * 1024 ? tier("high-2K", 439726) :
    tier("high-1K", 216849)
  ) : q == "medium" ? (
    px > 2048 * 2048 ? tier("medium-4K", 182877) :
    px > 1024 * 1024 ? tier("medium-2K", 109973) :
    tier("medium-1K", 54521)
  ) : (
    px > 2048 * 2048 ? tier("low-4K", 20548) :
    px > 1024 * 1024 ? tier("low-2K", 12329) :
    tier("low-1K", 6164)
  )
) * n + imgCount * 13699
```

> **输入图片计数逻辑**：  
> `param("image.#")` 用 gjson `#` 获取数组长度；`image` 为字符串（单张）时 `#` 不存在，按 1 张计；未传 `image` 时不收输入图费用。  
> **注意**：旧表达式把 `1024x1792` 标成 4K，实际约 1.8M 像素，现按总像素归入 2K。自定义大图（如 `2880x2880`）会进入 4K，不再掉进 1K 兜底。

### 8.5 Qwen 系列

#### qwen-image-0925

Qwen 使用 `size` 传像素尺寸（如 `1024x1024`），无标准 quality 档位。合法总像素范围 `[512×512, 2048×2048]`，最大 ~4.2M 像素。

> **注意**：Qwen 合法 size 的边长不超过 2048，因此永远不会出现含 `4096` 的 size，4K 档在实际使用中命中不到。建议运营确认是否需要保留 4K 档位，或简化为只有 1K/2K 分档。

用 `pixels()` 按总像素分档（比 `has()` 准确，不会误判如 `2048x512` 这类极端比例）：

```
pixels(param("size")) > 1024 * 1024 ? tier("2K", 52055) :
tier("1K", 41096)
```

> 如确实需要 4K 档，或所有用户均使用相同尺寸，也可直接配置固定价（如 `tier("1K", 41096)`）。

### 8.6 Hunyuan 系列

#### hunyuan-image-3.0

Hunyuan 使用 `size` 传像素尺寸，无标准 quality 档位。合法约束：宽高各维度 `[512, 2048]`，**宽×高乘积 ≤ 1024×1024**（约 1M 像素）。

> **注意**：Hunyuan 的像素乘积上限恰好是 1M（= 1K 档上界），2K 和 4K 档在实际使用中永远命中不到。建议配置固定价：

```
tier("1K", 27397)
```

> 若运营未来扩大了 Hunyuan 像素上限，可改用 `pixels()` 分档：
>
> ```
> pixels(param("size")) > 1024 * 1024 ? tier("2K", 38356) :
> tier("1K", 27397)
> ```
