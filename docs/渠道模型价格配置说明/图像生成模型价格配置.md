# 图像生成模型价格配置

> 平台对外报价以**人民币**显示，内部计费仍以**美元**结算，**固定汇率 7.3 CNY/USD**（不随市场波动调整）。  
> 表达式值计算公式：`表达式值 = 人民币单价 ÷ 7.3 × 1,000,000`  
> `param("quality")` 读取请求 body 中的原始 `quality` 字段（不做归一化），需兼容用户传入的别名（low/medium/high 等）。

### 8.0 gpt-image-2

#### 价格说明（新价格，2026.5.12 起生效）

**输入图片（参考图）：固定 0.100 元/张，与 quality 和 size 无关，按实际传入张数计费，不随 `n` 翻倍。**

| quality | 1K（元/张） | 2K（元/张） | 4K（元/张） |
|---------|-----------|-----------|-----------|
| low | 0.045 | 0.090 | 0.150 |
| medium | 0.398 | 0.803 | 1.335 |
| high | 1.583 | 3.210 | 5.340 |

> **计费结构**：总费用 = 生成成本（quality × size × n） + 输入图片成本（0.100 元 × 张数）  
> 输入图片成本**不受 quality、size、n 影响**，只看传了几张参考图。

#### 计费表达式

```
(param("quality") == "high" ? (
  param("size") == "1024x1792" || param("size") == "1792x1024" ? tier("high-4K", 731507) :
  param("size") == "1024x1536" || param("size") == "1536x1024" ? tier("high-2K", 439726) :
  tier("high-1K", 216849)
) : param("quality") == "medium" ? (
  param("size") == "1024x1792" || param("size") == "1792x1024" ? tier("medium-4K", 182877) :
  param("size") == "1024x1536" || param("size") == "1536x1024" ? tier("medium-2K", 109973) :
  tier("medium-1K", 54521)
) : (
  param("size") == "1024x1792" || param("size") == "1792x1024" ? tier("low-4K", 20548) :
  param("size") == "1024x1536" || param("size") == "1536x1024" ? tier("low-2K", 12329) :
  tier("low-1K", 6164)
)) * (param("n") != nil ? param("n") : 1) +
(param("image") != nil ? (param("image.#") > 0 ? param("image.#") : 1) * 13699 : 0)
```

> **输入图片计数逻辑**：  
> `param("image.#")` 用 gjson `#` 获取数组长度；`image` 为字符串（单张）时返回 `0`，此时按 1 张计；未传 `image` 时不收输入图费用。

#### kling-image-2.1

价格依赖**参考图数量**：
- `param("image") == nil` → 文生图
- `param("image.#") >= 2` → 多图参考生图（`image` 为 2+ 元素数组时）
- 其余（`image` 为字符串或单元素数组）→ 单图参考生图

> `param("image.#")` 使用 gjson `#` 操作符获取数组长度；`image` 为字符串时返回 0，未传时返回 nil。

```
(param("image") == nil ?
  ((param("quality") == "4K" || param("quality") == "4k") ? tier("t2i-4k", 35616) :
   (param("quality") == "2K" || param("quality") == "2k" || param("quality") == "hd" || param("quality") == "high") ? tier("t2i-2k", 13699) :
   tier("t2i-1k", 13699)) :
param("image.#") >= 2 ?
  ((param("quality") == "4K" || param("quality") == "4k") ? tier("multi-4k", 76712) :
   (param("quality") == "2K" || param("quality") == "2k" || param("quality") == "hd" || param("quality") == "high") ? tier("multi-2k", 65753) :
   tier("multi-1k", 54795)) :
  ((param("quality") == "4K" || param("quality") == "4k") ? tier("i2i-4k", 54795) :
   (param("quality") == "2K" || param("quality") == "2k" || param("quality") == "hd" || param("quality") == "high") ? tier("i2i-2k", 27397) :
   tier("i2i-1k", 27397))
) * (param("n") != nil ? int(param("n")) : 1)
```

- 无图 → 文生图价

### 8.5 Qwen 系列

#### qwen-image-0925

Qwen 使用 `size` 传像素尺寸（如 `1024x1024`），无标准 quality 档位。  
若运营希望按像素面积分档计费，可用 `has()` 匹配 size 字符串：

```
has(param("size"), "4096") ? tier("4K", 63014) :
has(param("size"), "2048") ? tier("2K", 52055) :
tier("1K", 41096)
```

> 如所有用户均使用相同尺寸，也可直接配置固定价（如 `tier("1K", 41096)`）。
