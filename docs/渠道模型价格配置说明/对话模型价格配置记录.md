# 对话模型价格配置记录

> 本文档记录平台各渠道**对话（文本生成）模型**的价格配置信息，包括官方刊例价、换算过程及后台填写值。
>
> 对话模型均使用「**按量计费**」方式，在模型倍率设置页面填写输入/输出价格（单位：$/1M tokens）。

---

## 说明：人民币刊例价 → 后台填写值 换算公式

```
后台填写值（$/1M tokens）= 官方刊例价（¥/千tokens）× 1000 ÷ 汇率
```

**本文档统一使用汇率：1 USD = 7.3 CNY**

---

## 京东渠道

### gpt-5.5

**渠道：** 京东（JoyAgent）
**更新时间：** 2026-08-06
**官方文档：** 京东 JoyAgent 平台刊例

#### 官网刊例价

| 档位 | 上下文范围 | 输入单价 | 输出单价 | 缓存读取单价 |
|------|-----------|---------|---------|------------|
| 标准档 | ≤ 272K tokens | ¥0.035 / 千tokens | ¥0.21 / 千tokens | ¥0.0035 / 千tokens |
| 长上下文档 | > 272K tokens | ¥0.07 / 千tokens | ¥0.315 / 千tokens | ¥0.007 / 千tokens |

> 京东刊例未标注缓存创建价格，暂不配置。

#### 后台填写值（汇率 7.3）

| 档位条件 | 输入价格 | 输出价格 | 缓存读取价格 |
|---------|---------|---------|------------|
| `len <= 272000`（standard） | **$4.79 / 1M** | **$28.77 / 1M** | **$0.48 / 1M** |
| 兜底档（long_context） | **$9.59 / 1M** | **$43.15 / 1M** | **$0.96 / 1M** |

#### 换算过程

```
标准档输入：  0.035  × 1000 ÷ 7.3 ≈ $4.79  / 1M tokens
标准档输出：  0.21   × 1000 ÷ 7.3 ≈ $28.77 / 1M tokens
标准档缓存读：0.0035 × 1000 ÷ 7.3 ≈ $0.48  / 1M tokens

长上下文输入：  0.07   × 1000 ÷ 7.3 ≈ $9.59  / 1M tokens
长上下文输出：  0.315  × 1000 ÷ 7.3 ≈ $43.15 / 1M tokens
长上下文缓存读：0.007  × 1000 ÷ 7.3 ≈ $0.96  / 1M tokens
```

#### 后台配置结构

```
计费方式：按量计费（阶梯）
第 1 档（standard）：条件 len <= 272000
  输入价格：4.79
  输出价格：28.77
  缓存读取价格：0.48
第 2 档（long_context，兜底档）：无条件
  输入价格：9.59
  输出价格：43.15
  缓存读取价格：0.96
```

### claude-opus-4-7

**渠道：** 京东（JoyAgent）
**更新时间：** 2026-08-06
**官方文档：** 京东 JoyAgent 平台刊例

#### 官网刊例价

| 项目 | 单价 |
|------|------|
| 输入 | ¥0.035 / 千tokens |
| 输出 | ¥0.175 / 千tokens |
| 缓存创建（5 分钟） | ¥0.04375 / 千tokens |
| 缓存创建（1 小时） | ¥0.07 / 千tokens |
| 缓存读取 | ¥0.0035 / 千tokens |

#### 后台填写值（汇率 7.3）

| 项目 | 后台填写值 |
|------|----------|
| 输入价格 | **$4.79 / 1M tokens** |
| 输出价格 | **$23.97 / 1M tokens** |
| 缓存创建价格（5 分钟，分时缓存 Claude） | **$5.99 / 1M tokens** |
| 缓存创建价格（1 小时，分时缓存 Claude） | **$9.59 / 1M tokens** |
| 缓存读取价格 | **$0.48 / 1M tokens** |

#### 换算过程

```
输入：    0.035   × 1000 ÷ 7.3 ≈ $4.79  / 1M tokens
输出：    0.175   × 1000 ÷ 7.3 ≈ $23.97 / 1M tokens
缓存创建5分钟：0.04375 × 1000 ÷ 7.3 ≈ $5.99  / 1M tokens
缓存创建1小时：0.07    × 1000 ÷ 7.3 ≈ $9.59  / 1M tokens
缓存读取：0.0035  × 1000 ÷ 7.3 ≈ $0.48  / 1M tokens
```

#### 后台配置结构

```
计费方式：按量计费（单档）
  输入价格：4.79
  输出价格：23.97
  缓存读取价格：0.48
  （扩展价格 → 分时缓存 Claude）
  缓存创建价格（5分钟）：5.99
  缓存创建价格（1小时）：9.59
```
