## 二、火山方舟 3D 配置



### 2.1 官方价格


| 模型                         | 官方价格             |
| -------------------------- | ---------------- |
| `doubao-seed3d-2-0-260328` | 80 元 / 百万 tokens |
| `hyper3d-gen2-260112`      | 60 元 / 百万 tokens |
| `hitem3d-2-0-251223`       | 80 元 / 百万 tokens |




### 2.2 后台配置方式

火山 3D 必须配置为 **按量计费**，只填界面里的输入价格（`$/1M tokens`）。

不要配置固定价格 / ModelPrice。火山 3D 查询接口会返回 `usage.total_tokens`，系统完成任务后会按实际 token 用量多退少补；如果配置成固定价格，会跳过 token 重算。

### 2.3 后台应填值

当前后台界面输入框显示的是 `$/1M tokens`，应按人民币官方价除以固定汇率 `7.3` 后填写：

```text
后台输入价格 = 官方人民币元/百万 tokens ÷ 7.3
```


| 模型                         | 官方价格             | 后台输入价格（$/1M tokens） | 保存后的内部 ModelRatio |
| -------------------------- | ---------------- | ------------------- | ----------------- |
| `doubao-seed3d-2-0-260328` | 80 元 / 百万 tokens | `10.9589`           | `5.47945`         |
| `hyper3d-gen2-260112`      | 60 元 / 百万 tokens | `8.2192`            | `4.1096`          |
| `hitem3d-2-0-251223`       | 80 元 / 百万 tokens | `10.9589`           | `5.47945`         |


> 说明：前端这个输入框是美元价展示。保存时会自动把输入价格除以 2 后写入内部 `ModelRatio`；例如填 `10.9589`，底层保存约为 `5.47945`，最终 100 万 tokens 约扣 `80` 元 × 分组倍率。



### 2.4 配置步骤

1. 打开模型倍率设置。
2. 选择对应火山 3D 模型。
3. 计费方式选择 **按量计费**。
4. 输入价格（`$/1M tokens`）按上表填写。
5. 固定价格 / ModelPrice 不要填写。
6. 输出价格、缓存价格、图片/音频价格保持为空或默认。

## 三、腾讯混元 3D 配置



### 3.1 官方价格

腾讯混元 3D 后付费统一单价：

```text
0.12 元 / 积分
```

不同模型和参数会消耗不同积分。代码会在提交前自动计算 `credits` 倍数，后台只需要配置“单积分价格”。

后台 ModelPrice 按美元计价，因此：

```text
后台 ModelPrice = 0.12 ÷ 7.3 ≈ 0.01644
```



### 3.2 后台配置方式

腾讯官方后付费是 **按积分计费**，不是每次请求固定扣同一个金额。由于当前后台没有“积分计费”这一种独立计费方式，需要选择 **按次计费** 入口，并把 `ModelPrice` 当作“单积分价格”填写：

```text
0.01644
```

这里的 `0.01644` 不是“一次请求价格”，而是 `0.12 元/积分 ÷ 7.3` 后得到的 **单积分美元价格**。不要把每种参数组合拆成多个模型价格，也不要写表达式。积分数量由适配器根据模型和参数自动计算为 `credits`，再参与扣费：

```text
实际预扣额度 = 单积分 ModelPrice × credits × QuotaPerUnit × group_ratio
```

### 3.5 专业版完成时校准

只有专业版查询接口明确返回 `ResultCreditConsumed`。因此：

- `hunyuan-3d-pro-3.0` 和 `hunyuan-3d-pro-3.1` 会先按预估积分预扣，任务成功后按查询返回的实际积分多退少补。
- 其他腾讯 3D 模型查询文档未提供实际积分字段，成功后保留提交阶段预扣额度。
- 所有腾讯 3D 模型失败时都会走任务失败退款，符合“生成失败不扣积分”。



### 3.6 配置步骤

1. 打开模型倍率设置。
2. 选择腾讯混元 3D 模型。
3. 计费方式选择 **按次计费**（后台借用该入口承载“单积分价格”）。
4. ModelPrice 填写单积分价格 `0.01644`。
5. 不要填写输入价格 / ModelRatio。
6. 不要配置表达式。
7. 保存后，用一个低积分模型测试提交与查询，确认扣费约等于 `credits × 0.12 元 × 分组倍率`。

## 五、配置检查清单

- 火山 3D：选择 **按量计费**，只填输入价格（`$/1M tokens`）。
- 火山 3D：不要填 ModelPrice。
- 火山 `doubao-seed3d-2-0-260328` 填 `10.9589`。
- 火山 `hyper3d-gen2-260112` 填 `8.2192`。
- 火山 `hitem3d-2-0-251223` 填 `10.9589`。
- 腾讯 3D：官方是后付费按积分，后台选择 **按次计费** 只是为了使用 ModelPrice 作为单积分价格。
- 腾讯 3D：ModelPrice 统一填单积分价格 `0.01644`，不是单次请求固定价格。
- 腾讯 3D：不要配置表达式，不要拆多个参数组合价格。
- 分组倍率如果不是 `1`，最终用户扣费会再乘以分组倍率。
