# 海外构建镜像并部署到生产服务器

## 一、海外服务器

```bash
# 1. 进入项目目录（改成你的路径）
cd /www/wwwroot/new-api-main

# 2. 拉代码
git pull

# 3. 构建镜像
docker compose build new-api

# 4. 查看镜像名
docker images | grep new-api
# 如果出现多个混淆名称，可以执行删除命令来删除，然后重新加载
# docker rmi new-api-main-new-api:latest
# docker rmi new-api-new-api:latest

# 5. 导出 tar（镜像名按上一步结果改，一般是下面这个）
docker save -o ./new-api-image.tar new-api-new-api:latest
# docker save -o ./new-api-image.tar new-api-main-new-api:latest

# 6. 确认文件
ls -lh ./new-api-image.tar
```

## 二、下载到本机

```bash
scp root@海外服务器IP:/www/wwwroot/new-api-main/new-api-image.tar ./
```

## 三、上传到生产服务器

```bash
scp ./new-api-image.tar root@生产服务器IP:/www/wwwroot/newapi/new-api-main/
```

## 四、生产服务器

```bash
# 1. 进入项目目录（改成你的路径）
cd /www/wwwroot/newapi/new-api-main

# 2. 导入镜像
docker load -i new-api-image.tar

# 3. 确认镜像
docker images | grep new-api
```

## 五、改 docker-compose.yml

把 `new-api` 里的：

```yaml
    build:
      context: .
      dockerfile: Dockerfile
```

改成：

```yaml
    image: new-api-new-api:latest
```

其余不要动。

## 六、启动

```bash
docker compose down
docker compose up -d
```

不要加 `--build`。

## 七、检查

```bash
docker compose ps
curl http://127.0.0.1:9006/api/status
```

## 八、下次更新

海外机重复「一」→「二」→「三」，生产机重复「四」→「六」→「七」。

# 本地构建镜像并部署到生产服务器

> 适用场景：不依赖海外服务器，直接在本地 Mac（Apple Silicon 或 Intel）构建 `linux/amd64` 镜像，再上传到生产服务器。

## 一、本地构建镜像

```bash
# 1. 进入项目目录
cd /Users/biaodi/workspace/company/whaleClub/mapiV2/new-api

# 2. 拉最新代码
git pull

# 3. 指定目标平台构建镜像（生产服务器为 amd64，必须加 --platform）
#    -t 可以同时打多个 tag，按需调整镜像名和版本号
docker build --platform linux/amd64 \
  -t new-api:latest \
  -t new-api:1.1.0 \
  .

# 4. 确认镜像已生成
docker images | grep new-api
```

> **注意**：Apple Silicon（M 系列芯片）上默认构建的是 `arm64` 镜像，必须加 `--platform linux/amd64` 才能在 x86 服务器上运行。

## 二、导出镜像为 tar 包

```bash
# 镜像名与上一步 -t 保持一致
docker save -o ./new-api-image.tar new-api:latest

# 确认文件大小
ls -lh ./new-api-image.tar
```

## 三、上传到生产服务器

```bash
scp ./new-api-image.tar root@生产服务器IP:/www/wwwroot/newapi/new-api-main/
```

## 四、生产服务器导入并启动

```bash
# 1. 登录生产服务器后进入项目目录
cd /www/wwwroot/newapi/new-api-main

# 2. 导入镜像
docker load -i new-api-image.tar

# 3. 确认镜像
docker images | grep new-api

# 4. 重启服务（不加 --build）
docker compose down
docker compose up -d
```

## 五、改 docker-compose.yml（首次使用时）

确保 `docker-compose.yml` 中 `new-api` 服务使用的是 **镜像模式**，而非构建模式：

```yaml
# 删除或注释掉这段
# build:
#   context: .
#   dockerfile: Dockerfile

# 改为指定镜像
image: new-api:latest
```

## 六、检查

```bash
docker compose ps
curl http://127.0.0.1:9006/api/status
```

## 七、下次更新

本地重复「一」→「二」→「三」，生产机重复「四」→「六」。
