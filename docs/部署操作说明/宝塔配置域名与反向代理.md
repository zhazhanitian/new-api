# 宝塔配置域名与反向代理

## 一、添加站点

宝塔面板 → **网站** → **添加站点**

- 域名：填你的域名，如 `api.mapi.zone`
- 根目录：随便填（不用于存文件）
- PHP：选**纯静态**

## 二、申请 SSL 证书

进入站点设置 → **SSL** → **Let's Encrypt**

- 勾选域名 → 点**申请**
- 申请成功后开启**强制 HTTPS**

## 三、添加反向代理

站点设置 → **反向代理** → **添加反向代理**

| 字段 | 填写内容 |
|------|----------|
| 代理名称 | `new-api` |
| 目标 URL | `http://127.0.0.1:9006` |
| 发送域名 | `api.mapi.zone` |
| 开启缓存 | **关闭** |

点**确定**。

## 四、补充超时与流式配置

站点设置 → 反向代理 → 点 `new-api` 右边的**配置文件**，将内容替换为：

```nginx
#PROXY-START/

location ^~ /
{
    proxy_pass http://127.0.0.1:9006;
    proxy_set_header Host api.mapi.zone;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header REMOTE-HOST $remote_addr;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection $connection_upgrade;
    proxy_http_version 1.1;

    proxy_read_timeout 300s;
    proxy_send_timeout 300s;
    proxy_connect_timeout 30s;
    proxy_buffering off;
    proxy_cache off;

    add_header X-Cache $upstream_cache_status;

    set $static_fileNE4JgT0o 0;
    if ( $uri ~* "\.(gif|png|jpg|css|js|woff|woff2)$" )
    {
        set $static_fileNE4JgT0o 1;
        expires 1m;
    }
    if ( $static_fileNE4JgT0o = 0 )
    {
        add_header Cache-Control no-cache;
    }
}

#PROXY-END/
```

保存。

## 五、重载 NGINX

宝塔面板右上角 → **重载配置**，或执行：

```bash
nginx -s reload
```

## 六、验证

```bash
curl https://api.mapi.zone/api/status
```

返回 `"success":true` 即正常。
